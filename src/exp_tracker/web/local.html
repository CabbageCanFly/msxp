    How do I add this to OBS?
    1. Pick your options above, then click Open pop-out. Keep that small window open (it can sit behind the game).
    2. In OBS, under Sources, click + → Window Capture → OK.
    3. Choose the window titled msxp overlay · On this device.
    4. Crop to the card (Alt+drag in OBS), or add a Chroma Key filter if you picked the green or magenta window background.

    A Browser Source can't show it: OBS uses its own browser, which can't see this browser's saved readings. The overlay shows progress only while this page is tracking; it never captures your screen itself.

    Game HUD

    After you start, msxp finds the EXP bar at the bottom of the game window. If it can't, open the preview and drag a box around the EXP numbers, then around the orange level badge.

    Your data

    Everything stays in this browser (IndexedDB). Detailed readings are kept for 24 hours; after that each character keeps one summary per day, indefinitely. Screen frames are read in memory and discarded after each scan. With Track pickups on, meso and item pickups read from the game's messages are kept the same way (24 hours). To read the HUD without OCR, msxp also keeps tiny black-and-white bitmaps of HUD characters it has already recognised.
