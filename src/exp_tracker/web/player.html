    How do I add this to OBS?
    1. Pick your options above, then click Copy URL.
    2. In OBS, under Sources, click + → Browser → OK.
    3. Paste the link into the URL box.
    4. Set Width and Height to the OBS size shown at the top of this panel. Leave everything else as it is.
    5. Click OK, then drag the overlay where you want it. It updates by itself.

    Changed your options later? Copy the new URL, right-click the source in OBS → Properties, and paste it over the old one. More help: OBS Browser Source guide ↗
