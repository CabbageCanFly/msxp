About msxp

MapleStory Classic launched in October 2026 without a built-in EXP tracker, and Nexon doesn't offer an API for character stats. So msxp watches MapleStory Classic streams on Twitch and reads each character's level and EXP bar straight from the stream video.

  • Nothing to download. Viewers just open this site. Streamers don't install anything either: msxp only watches the public stream.
  • EXP / hour, time to next level and EXP history for every tracked character, plus a free OBS overlay on each player's page.

Want a streamer added? Message me on Discord, Twitch, Twitter, Instagram or GitHub. I'm @cabbagecanfly everywhere, so use whichever works for you.

Why only Twitch? YouTube often blocks automated viewers running on servers, which is how msxp watches streams, so YouTube streams can't be tracked reliably for now.
